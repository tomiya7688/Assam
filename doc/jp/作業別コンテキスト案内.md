# 作業別コンテキスト案内

言語: 日本語 | [English](../en/task-context-map.md)

`AGENTS.md` の共通ルールを確認した後、今回の作業に合う行だけを入口にしてください。下記のパスはリポジトリルートからの相対パスです。まず `rg --files` / `rg -n` で候補を絞り、該当する原典とテストの必要箇所を読む。表にない作業や共有境界を変える作業では、利用側も追加で調べます。

| 作業 | 最初に確認する原典 | 最初の検証候補 |
| --- | --- | --- |
| テキスト構文・JSON IR | `assam/parser.py`, `assam/ir.py`, `assam/generator.py`, `doc/jp/命令セット仕様.md` | `tests/test_ir_labels.py`, `tests/test_assam.py` の該当ケース |
| VM・デバッガー・端末 | `assam/vm.py`, `assam/debugger.py`, `assam/terminal.py`, `doc/jp/命令セット仕様.md` | `tests/test_step_budget.py`, `tests/test_arithmetic_zero.py`, `tests/test_terminal_diagnostics.py` から該当ケース |
| Core profile・レジストリ | `assam/instruction_set.py`, `assam/profile.py`, `assam/data/instruction_registry.json`, `doc/jp/assam-core.md` | 変更した命令・profileを使うテストを `rg -n` で選ぶ。JSON変更時は対応schemaも確認 |
| ターゲット網羅・対応表 | `.agents/skills/assam-target-mappings/SKILL.md` の対象別手順、`assam/target_coverage.py`, `examples/targets/` | `tests/test_target_mappings.py`, `tests/test_target_matrix.py`, `tests/test_shipped_target_mappings.py` の該当ケース |
| C入力変換・静的解析 | `assam/c_frontend.py`, `assam/analyzer.py`, `doc/jp/C入力変換仕様.md`, `doc/jp/開発者評価ツール.md` | `tests/test_c_frontend_analyzer.py` の該当ケース |

CLI境界を変更する場合だけ `assam/cli.py` とそのコマンドを呼ぶテストを検索します。表は全ファイルを読む指示でも、影響範囲の上限でもありません。現行コードと食い違う行は修正してください。通常の調査では無関係なログ・キャッシュ・生成物を開かず、必要な検証では対象に戻します。
