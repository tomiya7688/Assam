# 作業別コンテキスト案内

言語: 日本語 | [English](../en/task-context-map.md)

`AGENTS.md` の共通ルールを確認した後、今回の作業に合う行だけを入口にしてください。下記のパスはリポジトリルートからの相対パスです。まず `rg --files` / `rg -n` で候補を絞り、該当する原典とテストの必要箇所を読む。表にない作業や共有境界を変える作業では、利用側も追加で調べます。
