## 設計と実装の関係

- 設計は**目標状態**を書く。現行実装との差は[全体設計 §4](全体設計.md)のギャップ表にある。実装が追いつくまで、設計書の内容が現行コードで成り立つとは限らない。現行コードの挙動は[命令セット仕様](../命令セット仕様.md)・[Assam Core](../assam-core.md)（Draft）を参照。
- 設計が不足・矛盾する場合は実装前に設計PRで直す（[実装計画 §4](実装計画.md)）。
