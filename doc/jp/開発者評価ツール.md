# 開発者向け静的評価ツール

言語: 日本語 | [English](../en/developer-analysis-tools.md)

`ProgramAnalyzer` はプログラムを実行せずに命令セット検証と構造分析を行う。JSON IRまたはASSAMテキストを受け取り、命令数、命令別件数、レジスタの読み書き回数、ゲストデータメモリの読み書きを行う命令数、ラベル、基本ブロック、制御フロー辺、到達不能命令を返す。レジスタ効果はレジストリの `read_operands` / `write_operands` に明記されたオペランド位置から数え、データメモリ効果は `data_memory_effects` から数える。VM内部のスタック操作や端末バスの効果はゲストデータメモリ件数には含めない。

## CLI

```text
python -m assam.cli analyze program.assam
python -m assam.cli analyze program.json --ir-json --format json
python -m assam.cli analyze core-program.assam --profile core
```

基本ブロックの範囲は命令インデックスの両端を含む。辺はブロックIDで表す。条件分岐とCallには分岐先と次命令の両方を辺として記録する。ReturnとHaltには静的な後続辺を設定しない。

Callの戻り動作や端末の実行時効果は追跡しないため、この結果は実行保証ではなく構造を確認するための静的な目安である。
